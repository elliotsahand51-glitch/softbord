# Softboard Web

Client-only React + Vite PWA. No document leaves the device. Original PDF bytes and image blobs are stored in IndexedDB separately from versioned document state. The drawing engine reuses the course's smoothing behavior and retains raw source points. No automatic shape recognition.

Contracts: `src/types.ts`. Coordinates are page-local CSS/PDF viewport points with the top-left origin. PDF pages use the PDF.js viewport at scale 1 including rotation. Object x/y is a page coordinate; stroke points are relative to that object. Stroke paths are local SVG paths generated from points. Width/height are bounds for selection. Object rotation is degrees about its bounding-box center. Stored object arrays are in paint order. PDF text-selection highlights are rect objects with opacity .28 and fill.

Ownership: root builds app shell, gallery, editor, styles, PWA and integration. Ink agent owns `src/lib/ink.ts`, `src/components/DrawingSurface.tsx`, related tests. Storage agent owns `src/lib/storage.ts`, `src/lib/backup.ts`, related tests. PDF agent owns `src/lib/pdf.ts`, `src/lib/export.ts`, `src/components/PdfBackground.tsx`, related tests. Shared types modified only by root.

Storage API planned: listDocuments(), loadDocument(id), saveDocument(doc), deleteDocument(id), putAsset(blob,name):Promise<string>, getAsset(id):Promise<AssetRecord|undefined>, duplicateDocument(id):Promise<SoftDocument>, setDocumentCompressed(id,boolean), requestPersistence(). saveDocument returns the saved SoftDocument with incremented revision. Reject stale revisions instead of overwriting.

PDF API planned: importPdf(file:File):Promise<SoftDocument>; PdfBackground props {document,page,scale,textSelection,onTextHighlight(rects:Array<{x,y,width,height}>)}, page is BoardPage. Exports: exportPdf(document,onProgress?), exportPng(document,pageIndex), buildPageSvg(document,pageIndex):Promise<string>. Export functions return Blob; no implicit download. PDF backgrounds should release/cancel render tasks on unmount.

DrawingSurface props: page, settings, view, onViewChange, onChange(objects), selectedIds, onSelectionChange, onEditText(object), onInsertText(point,type), children (PDF background), onContextMenu? All mutable gestures commit once via onChange; update overlay imperatively during writing to avoid rerendering completed objects. Expose page coordinates under pan/zoom. Touch uses one-finger pan when penOnly, two-finger pan/pinch; pen draws independent of touch.

Continuous PDF reader: PdfReader owns a native scroll container with page wrappers positioned in document order. All PDF pages share a scale; fit width follows viewport size. DrawingSurface keeps page-local coordinates, with view x/y fixed at zero; wheel input scrolls the reader. Page backgrounds and annotation surfaces mount near the visible region, retaining the active page during a gesture. Shared touch tracking cancels a one-finger preview before two-finger scrolling, even across page boundaries. Pen ownership blocks palm input across the entire reader. Text dialogs and asynchronous image insertion retain their originating page ID. Refresh state stores a page-relative vertical offset, horizontal center and explicit scale or fit-width mode in per-tab session storage. The PDF coordinate/export contract is unchanged.
